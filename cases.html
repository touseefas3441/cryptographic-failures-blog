02 / Real-World Examples

Case Studies

These cases show how weaknesses in cryptographic software and random number generation can affect real systems.

01
2014 · OPENSSL

Heartbleed

Heartbleed was a vulnerability in OpenSSL's implementation of the TLS Heartbeat extension.

The bug could allow attackers to read small sections of memory from vulnerable servers. Depending on what was stored in memory, this could include passwords, session information or private keys.

The important lesson is that using a trusted cryptographic protocol is not enough if the software implementing it contains a serious flaw.

02
2006–2008 · DEBIAN OPENSSL

Debian OpenSSL Bug

A change made to Debian's OpenSSL package accidentally removed code used by the random number generator.

This resulted in a much smaller set of possible cryptographic keys being generated on affected systems.

Because cryptographic security depends heavily on unpredictable keys, attackers could identify affected keys more easily than they should have been able to.

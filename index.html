Why do cryptographic failures matter?

We use websites and applications every day to send information that should remain private. This can include passwords, payment details, messages and personal information.

Cryptography is one of the technologies used to protect this information. Encryption can, for example, make data unreadable to someone who should not have access to it.

But using cryptography does not automatically make a system secure. Developers can choose outdated algorithms, store passwords incorrectly or accidentally expose secret keys.

These kinds of problems are known as cryptographic failures.

OWASP lists Cryptographic Failures as A04:2025 in the OWASP Top 10:2025. The category includes issues such as weak cryptography, exposed keys and unsafe password storage.

Who is affected?

01 / USERS

Users

Poor protection can expose accounts, passwords or personal information.

02 / DEVELOPERS

Developers

Incorrect implementation or configuration can introduce security weaknesses.

03 / ORGANIZATIONS

Organizations

Security incidents can result in financial, legal and reputational problems.

04 / SYSTEMS

Applications

Weak cryptographic controls can affect the confidentiality and integrity of data.

The prevention section covers practical ways developers can reduce these risks.

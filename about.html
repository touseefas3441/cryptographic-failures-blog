About This Blog

A small student project exploring one of the common problems in application security.

Why this project?

This blog was created as part of an Information Systems and Cybersecurity project.

The goal is to explain cryptographic failures in a simple way instead of using only technical definitions.

The website combines research, real-world examples and a small interactive demonstration.

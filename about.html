Platform Comparison

Before developing the blog, three publishing platforms were considered using the following criteria:

  • Availability of a free option
  • Ease of publishing
  • Control over HTML/CSS
  • Ability to include an interactive demonstration
  • Suitable URL for an academic project
Platform Free Option Customization Interactive Demo Notes
WordPress.com Yes Good, but some features depend on the plan Possible with suitable features/code Designed for blogging and provides many publishing features.
Blogger Yes Moderate Possible with HTML/JavaScript Simple blogging platform with Google integration.
GitHub Pages Yes High control over static HTML/CSS/JavaScript Yes Suitable for a technical student project and static educational website.

Why GitHub Pages Was Selected

GitHub Pages was selected based on the project criteria because it allows the student to directly create and publish HTML, CSS and JavaScript files.

This is particularly useful for this topic because the blog includes an original interactive cryptographic demonstration.

GitHub Pages is also available for public repositories on GitHub Free, making it suitable for this student project.

The selection is based on the requirements and needs of this project rather than claiming that one publishing platform is universally better than all others.

Audience Feedback

Feedback will be collected from classmates using a short informal review.

Reviewers can comment on:

  • Clarity of explanations
  • Ease of navigation
  • Visual readability
  • Understanding of the safe demonstration
  • Broken links or technical problems

Feedback will be used to identify unclear sections and correct technical or navigation problems before the final presentation.

Safety Approach

This project does not perform unauthorized testing against real systems.

The demonstration uses fictional input and browser-based cryptographic functionality. No real accounts, passwords or external systems are attacked or tested.

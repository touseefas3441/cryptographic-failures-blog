What Are Cryptographic Failures?

Cryptography is the use of mathematical techniques to protect information. Web applications use cryptographic mechanisms to help protect sensitive information such as passwords, personal data, financial information and communications.

A cryptographic failure occurs when sensitive information is not properly protected because cryptography is missing, weak, incorrectly implemented, incorrectly configured or otherwise unsuitable for the security requirement.

Encryption

Encryption transforms readable information, known as plaintext, into a protected form called ciphertext. A suitable decryption process can transform the ciphertext back into readable information.

Hashing

Hashing is different from encryption. A cryptographic hash function produces a fixed-length value from input data. Proper password storage normally uses a password-hashing mechanism designed for password protection rather than storing the original password.

Encryption vs Hashing vs Encoding

Important: Encryption, hashing and encoding are not the same thing.

Encryption

Encryption is designed to protect information so that authorised parties can recover the original information using the appropriate decryption process.

Hashing

Hashing produces a derived value from input data. Password systems use specialised password-hashing algorithms to make password recovery from stored values difficult.

Encoding

Encoding changes data into another representation for compatibility or transmission. Encoding by itself does not provide confidentiality.

How Can Cryptographic Failures Happen?

Cryptographic problems can appear in many different ways. Examples include:

  • Transmitting sensitive information without appropriate protection.
  • Using obsolete or inappropriate cryptographic algorithms.
  • Storing passwords in plaintext.
  • Using weak password-storage mechanisms.
  • Poor management or storage of cryptographic keys.
  • Using predictable or inappropriate random values.
  • Incorrectly configuring TLS or other security mechanisms.
  • Hard-coding sensitive cryptographic secrets into application code.

Why Web Applications Are Affected

Web applications frequently handle information belonging to many users. This makes the protection of data an important part of application security.

Key lesson: Cryptography is not automatically secure simply because an application uses an encryption library. The algorithm, implementation, configuration, keys and surrounding security controls all matter.

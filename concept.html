01 / The Basics

The Concept

Cryptography protects information, but weak algorithms, poor implementation and bad key management can make that protection fail.

What is cryptography?

01

Encryption

Encryption changes readable information into unreadable data so that only authorised users can access it.

02

Hashing

Hashing converts data into a fixed-length value. Even a small change in the original data creates a different hash.

03

Keys

Cryptographic keys are used to encrypt, decrypt or protect information. If a key is exposed, the protection can fail.

What is a cryptographic failure?

A cryptographic failure happens when sensitive information is not properly protected because of weak algorithms, incorrect implementation, exposed keys, poor password storage or outdated security methods.

Common examples

Weak Algorithms

Using outdated or broken cryptographic algorithms can make protected data easier to attack.

Plaintext Passwords

Storing passwords as readable text means that a database leak can expose users' passwords directly.

Weak Hashing

Fast or outdated hashing methods can make password cracking much easier.

Exposed Keys

If secret encryption keys are stored or shared incorrectly, attackers may be able to access protected information.

Poor Randomness

Cryptographic systems need secure random values. Predictable randomness can make keys and tokens vulnerable.

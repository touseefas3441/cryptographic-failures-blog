The Concept

Cryptography is meant to protect information. A cryptographic failure happens when that protection is weak, missing or used incorrectly.

On this page 01 — What is cryptography? 02 — What is a cryptographic failure? 03 — Common examples

What is cryptography?

Cryptography is a way of protecting information using mathematical techniques.

It is commonly used to protect data while it is stored or being sent between systems.

🔒

Encryption

Turns readable information into protected data.

#️⃣

Hashing

Creates a fixed-length value from input data.

🔑

Keys

Secret values used by many cryptographic systems.

What is a cryptographic failure?

A cryptographic failure does not necessarily mean that the encryption algorithm itself is broken.

The problem can come from choosing the wrong algorithm, using it incorrectly or protecting the cryptographic keys badly.

Simple idea: Strong cryptography can still lead to a weak system if it is implemented badly.

Common examples

01
Using outdated or weak cryptographic algorithms.
02
Storing passwords without proper hashing.
03
Exposing private or secret cryptographic keys.
04
Using predictable random values where security requires randomness.
05
Using encryption incorrectly or with unsafe settings.

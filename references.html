References

The following sources were used to research the technical concepts, real-world examples and practical demonstration used in this project.

Technical & Security Sources

1. OWASP — Cryptographic Failures

OWASP Top 10 information about cryptographic failures, including common problems with sensitive data protection.

https://top10.owasp.org/2025/A04_2025-Cryptographic_Failures/

2. NIST — Computer Security Resource Center

NIST resources and publications covering cryptography, cybersecurity standards and security practices.

https://csrc.nist.gov/

3. Heartbleed

Information about the Heartbleed vulnerability in OpenSSL and its technical impact.

https://heartbleed.com/

4. Debian Wiki — SSL Keys

Documentation about the Debian OpenSSL random number generation issue and affected cryptographic keys.

https://wiki.debian.org/SSLkeys

5. MDN Web Docs — SubtleCrypto.digest()

Technical documentation used for the JavaScript SHA-256 demonstration on the Demo page.

https://developer.mozilla.org/en-US/docs/Web/API/SubtleCrypto/digest

Practical Demonstration

PowerShell SHA-256 Test

A local PowerShell test was performed as part of this project. The text "Hello World" was hashed using SHA-256 and then compared with the result after changing one character.

The screenshots from this test are included on the Demo page.

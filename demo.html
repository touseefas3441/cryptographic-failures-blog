SHA-256 Test

A simple practical test showing how a small change in data can completely change its hash.

How does this work?

01 — Input

A piece of text is entered into the SHA-256 function.

02 — Hashing

SHA-256 processes the input and creates a fixed-length hash value.

03 — Result

If the input changes, the resulting hash also changes completely.

My Practical Test

I used PowerShell to test SHA-256 with two almost identical inputs. The only difference was one letter.

Test 1: I entered "Hello World" and generated its SHA-256 hash.

Test 2: I changed "World" to "world". The resulting hash was completely different.

What I noticed

Only one character was changed, but the whole SHA-256 hash changed. This shows how sensitive cryptographic hash functions are to changes in data.

Why is this useful?

Hashes can be used to check whether data has been changed. They are commonly used for things such as file integrity checks and password storage systems.

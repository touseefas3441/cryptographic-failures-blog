About This Demonstration

This demonstration shows how a cryptographic hash can transform input data into a fixed-length digest.

The demonstration uses the SHA-256 hashing function through the browser's built-in Web Crypto API.

Safety notice:

This is a local educational demonstration. It does not connect to or test another website, database, account, server, or real user information.

For the demonstration, use fictional text rather than a real password or other sensitive information.

Step-by-Step Demonstration

Step 1:

Enter some fictional text in the box below.

Step 2:

Click the "Generate SHA-256 Hash" button.

Step 3:

The browser calculates the SHA-256 digest and displays the result.

Step 4:

Change one character in the input and generate the hash again. The resulting digest will change significantly.

What Happened?

The browser took the text entered into the demonstration and processed it using SHA-256.

SHA-256 produces a fixed-length 256-bit digest. The same input will produce the same digest, while changing the input changes the resulting digest.

A hash is different from encryption. Encryption is designed to allow authorized parties to recover the original data using the appropriate key. A cryptographic hash is designed as a one-way transformation.

Important Security Lesson

SHA-256 alone should NOT be used for storing passwords.

SHA-256 is a fast general-purpose hash function. Password storage requires password-hashing algorithms designed to make password guessing more expensive.

Modern password-storage guidance recommends dedicated algorithms such as Argon2id, scrypt, bcrypt, or PBKDF2, together with appropriate salts and configuration.

Therefore, this demonstration teaches the concept of hashing, but it is not an example of a production password-storage system.

Why This Demonstration Is Safe

  • It uses fictional information.
  • It runs in the visitor's browser.
  • It does not attempt to access another website.
  • It does not test authentication systems.
  • It does not perform password cracking.
  • It does not attack or scan any external system.

Technical Explanation

The demonstration uses the browser's Web Crypto API. The JavaScript calls the SHA-256 digest function and converts the resulting bytes into hexadecimal text for display.

This allows the demonstration to show a real cryptographic operation without requiring a backend server or external security-testing environment.

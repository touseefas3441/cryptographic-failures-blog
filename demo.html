My Practical Test

I also tested SHA-256 using PowerShell. First I created a file containing "Hello World". Then I changed it to "Hello world" and calculated the hash again.

Test 1 — "Hello World"

Test 2 — Hash comparison

Only one character was changed, but the hash changed completely. This shows how sensitive a hash function is to changes in data.

Why Is This Useful?

Hashes can be used to check if data has changed. They are also used in areas such as file integrity checks and password storage.

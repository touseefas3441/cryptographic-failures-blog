03 / Security Practices

Prevention

Good cryptography is not only about choosing encryption. It also depends on how keys, passwords and software are handled.

01

Use Modern Algorithms

Use established algorithms and protocols that are currently considered secure. Avoid outdated or broken methods.

02

Protect Secret Keys

Encryption keys should be protected and should not be exposed in source code, public repositories or unsecured files.

03

Hash Passwords Properly

Passwords should not be stored as plaintext. Use password hashing methods designed to resist cracking.

04

Use Secure Randomness

Cryptographic keys, tokens and other security values should be generated using secure random number generators.

05

Keep Software Updated

Security vulnerabilities can exist inside cryptographic libraries. Regular updates help reduce exposure to known bugs.

06

Follow Trusted Guidance

Use recognised standards and security guidance instead of creating custom cryptographic solutions.

One important rule

Don't create your own cryptography when tested and trusted solutions already exist. Most applications should rely on well-established libraries and standards.

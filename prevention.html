03 / Real World

Real-World Cases

Cryptographic and security failures are not just theoretical. Similar weaknesses have affected real systems.

CASE 01 / HEARTBLEED

Heartbleed

Heartbleed was a serious vulnerability in OpenSSL discovered in 2014.

It could allow sensitive information from a vulnerable server's memory to be exposed.

Lesson: Security software still needs testing, maintenance and updates.
CASE 02 / EQUIFAX

Equifax

In 2017, Equifax suffered a major data breach that exposed sensitive information.

The incident involved an unpatched vulnerability in a web application.

Lesson: Security depends on more than encryption. Patching and maintenance also matter.

Evidence

This section shows some of the real examples and practical evidence used in this project.

Real Examples

01

Heartbleed

Heartbleed was a vulnerability in OpenSSL. It could allow an attacker to read parts of a vulnerable server's memory, which could contain sensitive information.

02

Debian OpenSSL Bug

A change in Debian's OpenSSL package affected random number generation. This made some cryptographic keys predictable.

03

SHA-256 Test

My practical test shows that changing one character in the input creates a completely different SHA-256 hash.

04

OWASP Guidance

OWASP explains common cryptographic failures and gives guidance on protecting sensitive information.

My Practical Evidence

I tested SHA-256 using PowerShell and saved screenshots of the results. These screenshots are shown on the Demo page.

The test is a simple demonstration of how hashing reacts to changes in data. It is not meant to be a complete security test.
